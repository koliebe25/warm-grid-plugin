# 웜톤 격자 강의 인포그래픽 플러그인

따뜻한 아이보리 격자 배경과 카드 구성으로, 강의실에서 읽기 편한 인포그래픽·슬라이드를 만들어 주는 Claude Code 플러그인입니다.

## 1. 설치하기

설치 방법은 두 가지입니다. 편한 쪽을 하나만 고르세요.

### 방법 A. GitHub에서 설치 (인터넷만 있으면 됩니다)

1. Claude Code를 열고 아래 두 줄을 차례로 입력합니다.

```
/plugin marketplace add koliebe25/warm-grid-plugin
/plugin install warm-grid-lecture-infographic@yang-lecture-tools
```

2. 설치가 끝나면 Claude Code를 한 번 껐다가 다시 켭니다.

### 방법 B. zip 파일로 설치

1. 받은 zip 파일을 원하는 곳에 압축을 풉니다. 예: `C:\plugins\warm-grid-plugin`
   - 설치한 뒤에는 이 폴더를 지우거나 옮기지 마세요.
2. Claude Code를 열고 아래 두 줄을 차례로 입력합니다. 경로는 압축을 푼 위치로 바꿉니다.

```
/plugin marketplace add C:\plugins\warm-grid-plugin
/plugin install warm-grid-lecture-infographic@yang-lecture-tools
```

3. 설치가 끝나면 Claude Code를 한 번 껐다가 다시 켭니다.

## 2. 설치됐는지 확인하기

Claude Code에서 `/`를 입력하고 `warm-grid`를 검색합니다.
`warm-grid-lecture-infographic`이 보이면 설치된 것입니다.

## 3. 사용하기

만들고 싶은 자료를 말로 요청하면 됩니다. 아래처럼 목적, 대상, 핵심 문구를 함께 적으면 결과가 좋아집니다.

```
웜톤 격자 강의 인포그래픽 스타일로 "생성형 AI 업무 활용 3단계"를 만들어줘.
대상은 50대 직장인이고, 카드는 3개, 마지막 줄에는 "AI는 초안, 결정은 사람"을 넣어줘.
```

스킬이 자동으로 적용되지 않으면 이름을 직접 불러 주세요.

```
/warm-grid-lecture-infographic:warm-grid-lecture-infographic 프롬프트 작성법 4단계를 만들어줘
```

### 요청 예시

- "이 내용을 16:9 인포그래픽 한 장으로 만들어줘"
- "카드 4개로 비교하는 슬라이드로 만들어줘"
- "발표자료(PPT)로 만들어줘. 같은 스타일로"
- "내용이 많으니 두 장으로 나눠줘"

## 4. 알아두세요

- **디자인 기준:** 16:9 가로, 아이보리 바탕, 흰색 카드, 테라코타(주황 갈색) 포인트, 하단에 핵심 한 문장 상자입니다. 다른 비율이나 형식이 필요하면 요청할 때 말씀하세요.
- **글꼴:** 페이퍼로지(Paperlogy) 글꼴을 우선 사용합니다. 컴퓨터에 설치되어 있지 않으면 대체 글꼴이 쓰이며, Claude가 그 사실을 알려 줍니다. 이미지로 생성한 결과는 글꼴이 정확히 적용되지 않을 수 있습니다.
- **꼭 확인하세요:** 결과물의 한국어 오탈자, 글자 잘림, 글자 크기는 직접 한 번 확인하세요.
- **저장:** 기존 파일은 덮어쓰지 않고 새 이름으로 저장됩니다. 저장 위치는 Claude가 알려 줍니다.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| `warm-grid`가 검색되지 않음 | Claude Code를 껐다 다시 켠 뒤 확인합니다. 그래도 없으면 설치 명령을 다시 입력합니다. |
| 경로를 찾을 수 없다는 오류 | 압축을 푼 폴더 경로가 맞는지, 폴더 안에 `.claude-plugin` 폴더가 있는지 확인합니다. |
| 스타일이 적용되지 않음 | 요청에 "웜톤 격자 강의 인포그래픽 스타일로"라고 적거나 위의 `/warm-grid-...` 명령으로 직접 호출합니다. |
