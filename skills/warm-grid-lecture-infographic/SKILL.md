# 웜톤 격자 강의 인포그래픽

성인 학습자가 멀리서도 내용을 쉽게 읽을 수 있는 단정한 교육 자료를 만든다. 주제와 내용은 사용자의 요청에 맞추고 카드 수나 화면 비율도 내용에 맞게 조정한다. 스타일 기준은 [참고 이미지](assets/style-reference.png)다. 실제 예시 이미지를 참조할 수 있는 도구에서는 이 이미지를 스타일 참고로 사용한다.

## 디자인 기준

- 기본 구성은 가로 16:9, 따뜻한 아이보리 바탕에 눈에 거슬리지 않는 가는 격자다. 화면 가장자리와 요소 사이에 충분한 여백을 둔다. 참고 이미지처럼 내용 영역이 화면을 꽉 채우지 않게 하되, 강의실에서 읽을 수 있는 크기를 유지한다.
- 상단에 작은 테라코타 주제 표시와 큰 제목을 가운데 놓는다. 제목의 핵심 단어는 테라코타, 나머지는 짙은 네이비로 강조한다.
- 본문은 흰색 카드, 얇은 베이지 테두리와 둥근 모서리로 구분한다. 카드에는 단순한 외곽선 아이콘, 굵은 제목, 연한 살구색 띠의 한 줄 설명, 짧은 상세 설명을 둔다. 관계가 있을 때에만 간결한 화살표를 넣는다.
- 하단에 가장 중요한 메시지 한 문장을 얇은 테라코타색 테두리 상자에 담는다. 정보가 복잡하면 장수를 나누고 카드 개수는 내용에 맞춘다.
- 색상 기준: 아이보리 #FAF6F0, 네이비 #172033, 테라코타 #C9552D, 청록 #087F78, 카드 흰색 #FFFFFF, 테두리·격자 #E7DCD2, 설명 띠 #F4E9E1, 보조 브라운 #705C50. 색상은 매체와 가독성에 맞춰 미세 조정한다.
- 글꼴은 페이퍼로지(Paperlogy)를 우선 사용한다. 편집 가능한 결과물에서는 설치 또는 사용 가능한 실제 글꼴 파일을 확인해 적용한다. 사용할 수 없다면 사용자에게 알리고 대체 글꼴을 명시한다. 이미지 생성 결과는 페이퍼로지 스타일을 요청하되 실제 글꼴 적용을 보장하지 않으므로 그 사실을 분명하게 밝힌다.
- 아이콘은 단순한 외곽선과 균일한 선 굵기를 유지한다. 프로젝트·아티팩트·코드 비교에서는 참고 이미지의 폴더, 문서가 있는 모니터, 코드 꺾쇠와 슬래시를 사용한다. 다른 주제는 그 내용에 맞는 아이콘을 사용한다.
- 입체 효과와 장식은 최소화하고 한 카드에 한 개념을 담는다. 한국어 문구는 자연스럽고 짧게 쓴다. 배경과 본문 대비를 충분하게 유지한다.

## 제작과 전달

1. 목적, 수강 대상, 핵심 문구를 반영해 화면 구성을 정한다. 사용자가 별도 비율이나 형식을 요청하면 그 요청을 우선한다.
2. 이미지일 때는 사용 가능한 이미지 생성·편집 도구에 참고 이미지를 전달한다. 발표자료 등 편집 가능한 결과물은 해당 형식의 제작 도구로 같은 스타일을 구현한다.
3. 이미지나 완성 문서를 살펴 한국어 오탈자, 잘림, 대비와 글자 크기를 확인한다. 생성형 이미지에서는 정확한 글꼴·문구 구현이 보장되지 않음을 고려한다.
4. 기존 파일을 보존하고 새 이름으로 저장한다. 결과물의 저장 위치와 실제 글꼴 적용 여부를 알린다.
